# eBliss Theme

Shared visual foundation for eBliss web apps.

## Use

Load the pinned stylesheet from a web app's HTML:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/emptinessbliss15-cell/eBliss-Theme@017c0421fd4800cd5c63b743aacac925f7e62e41/theme.css">
```

Pinning to a commit keeps an app stable while the shared theme evolves. Apps can move to a newer theme commit intentionally.

## Core classes

- `.eb-container` — centered application container
- `.eb-card` — shared surface/card
- `.eb-muted` — secondary text
- `.eb-row` — responsive horizontal control group
- `.eb-spread` — spaced header/action row
- `.eb-list` — list spacing
- `.secondary` — secondary button treatment

The theme also provides shared CSS variables for background, surface, text, borders, accent, spacing, radius, and shadows, including automatic dark-mode support.
